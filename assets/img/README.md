# Imagens

Pasta reservada para fotos reais de projetos DYNEW (hero, galeria).

Atualmente a página usa blocos de espaço reservado (placeholders) em CSS/HTML no lugar de imagens reais — nenhuma imagem real de projeto foi fornecida ainda.

Ao adicionar fotos:
- Prefira formato `.webp` (com fallback `.jpg` se necessário).
- Otimize o tamanho de arquivo antes de subir.
- Atualize os elementos `.hero-media` e `.gallery-item` em `index.html` para usar `<img>` no lugar do placeholder.
