# Favicon

O favicon atual é um SVG provisório embutido diretamente no `<head>` de `index.html` (sem depender de arquivo binário).

Quando a identidade visual oficial da DYNEW for definida, gere os arquivos de favicon reais (ex: `favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`), coloque-os nesta pasta e atualize as tags `<link rel="icon">` em `index.html`.
